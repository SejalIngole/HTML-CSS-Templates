# 🚗 Car Rental Website

A responsive car rental website built using **HTML5 and CSS3**. This project focuses on creating a clean, user-friendly interface for browsing cars and exploring a car rental service across different screen sizes.

## ✨ Features

* 📱 Responsive website layout
* 🚘 Car rental-themed user interface
* 🎨 Custom styling using CSS
* 💻 Clean and structured HTML
* 🌐 Deployed using Netlify

## 🛠️ Technologies Used

* HTML5
* CSS3
* Netlify (Deployment)

## 🌍 Live Demo

[Visit Car Rental Website](https://carrennntal.netlify.app/)
